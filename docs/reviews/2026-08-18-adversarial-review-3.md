## What changed
- Lesson pins Full main + J1; quiz before/after use the same sail; auto sail selection only runs when the trimmers hold a target heel (manual power → biggest ranked combination); default sandbox sail = Full main + J1; auto copy made honest.
- Sail ladder: change-down threshold 0.6, headsail areas J2 44 / J3 37 / J4 29 m² (≈95/80/62 % LP). Hiking crew: J1 to 16 kn, J3 18, reef 1 + J3 20, reef 2 + J4 22+.
- Roll inertia expressed as (0.61·B)²·Δ (T ≈ 4 s); trajectory carries overpowered flags; Puff disabled when already overpowered; puff-overpowered labelled instead of a fake static line.
- Puff panel lives inside the stern-view panel (button, animation and trace on one screen); playback clock moved to a tiny external store (useSyncExternalStore) so only the stern view and trace re-render at 60 fps.
- Compare: unchanged rows neutral, overpowered/no-free-wind rendered as "over"/"–"; formation A drawn as filled grey "A" discs.
- Quiz: no default guess (Reveal disabled until the slider moves), Skip button, validated localStorage, cleared by the error-boundary reset.
- Crew sheet: occupied chips show ⇄ + initials in grey with aria-labels, bars share the crew-list scale, posture deltas carry units, focus moves into the dialog and back; Enter on a deck marker opens the sheet; snap animation respects prefers-reduced-motion.
- Service worker precaches the shell, network-first for HTML, cache-first only for hashed assets.
