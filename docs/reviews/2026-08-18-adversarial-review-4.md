## What changed
- Phone: coarse-pointer sizes (≥40 px buttons/chips, 16 px dots, 28 px sliders); taps near a marker select the nearest crew (proximity hit-test), taps near a slot move the selected crew; sheet no longer shows a focus ring; rail numbers sit outside the hull in portrait.
- Lesson: each step has a `focus` panel that is placed directly under the lesson card on phones (and in presenter mode); presenter keeps Compare and Sitting-vs-hiking.
- Puff: crew move ramps over 1.5 s from `reactAt` (0.5–3 s slider), peak monotone in reaction time; narrow layout with a caption instead of overlapping in-plot labels; sign fix.
- Share: pinned A encoded in the URL (`a=`), native share sheet on phones, visible feedback when the clipboard is blocked.
- Engineering: SW precaches this build’s js/css with a per-build cache name (Vite plugin) and evicts old caches; Google Fonts non-blocking; CI runs `npm run build` (tsc + eslint + vite); global key handlers respect `defaultPrevented`; debounced `aria-live` status; consistent HM labelling; boat-speed source labelled (card vs polar, provisional flag); "static model" claims corrected for the puff.
